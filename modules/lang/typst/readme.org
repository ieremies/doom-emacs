* Previewing
There are two options:
- using ~typst-ts-watch-mode~ and using something like ~super-save~ to automatically save the file.
- using [[https://github.com/havarddj/typst-preview.el][havarddj/typst-preview.el]], which allows you to click and navigate to the source code at point.
  - when previewing slides: ~(setq-local typst-preview-preview-mode "slide")~.
